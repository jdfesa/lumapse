## Fallo reproducido — OFF-05

En la APK inicial, Opciones → Exportar ZIP muestra «Sin conexion» y deshabilita
Exportar ZIP. El texto exige internet incluso para un destino local. No se genera
el ZIP ni se abre el selector. **FAIL al exportar**, no una importación fallida.

La causa está en `BackupFlowService`: la disponibilidad del destino externo se usaba
para bloquear también la generación local. Las pruebas históricas exigían ese
bloqueo. Contradice OFF-05 y [HU-030 CA-03](../producto/historias-de-usuario.md#hu-030--crear-backup-manual-externo).

## Artefacto de la corrección y método

`npm run deploy:android -- --target <dispositivo-test>` terminó en exit 0, sin
`--clean`, usando Node 22.20.0/npm 10.9.3, JDK 21, SDK, caché Gradle y configuración
debug existentes. `signingReport --offline` comprobó la firma original; no se instaló
tooling ni se cambió la firma versionada. El teléfono tuvo que despertarse para
completar el lanzamiento; un timeout de inspección durante ese lanzamiento no fue
una prueba de la app ni se contó como PASS.

- Debug privado `0.5.0/500`, canal Android debug, fuente limpia
  `348da88c89466917b1d057a5bd53a1cd0d524642`, comprobada en Acerca de.
- SHA-256 APK generado e instalado, coincidentes:
  `572b15acf6f0a11d6bce5d0f49bb24a22378fb5098542ddcd6007e9f65379ab2`.
- Certificado SHA-256 igual al original indicado arriba; no candidato ni release.

Las acciones de notas/fechas se ejecutaron mediante controles y eventos DOM del
WebView del APK inspeccionado, con SQLite/bridge reales: sin importar módulos del
producto, llamar servicios directamente ni escribir SQL. Selector de compartición,
gestor local y selector de importación se operaron como UI nativa por ADB.
Las consultas SQLite se realizaron **en copias privadas de lectura**. La transferencia
directa mediante `su` contaminó la primera copia; se descartó como evidencia y se
validó otra mediante base64/hash e integridad, sin atribuir corrupción al teléfono.

La reapertura de notas/fechas fue Home → volver a la actividad, no SIGKILL ni reinicio
físico. El arranque del debug ocurrió sin red. No se repitieron las pruebas de
continuidad RNF-010 ni se midieron tiempos/FPS. Dos lecturas auxiliares prematuras
se corrigieron sin reenviar la creación; pulsar un día ya seleccionado quita el
filtro, no pierde la fecha. UIAutomator terminó en 137 una vez en el gestor; se
usó una captura inspeccionada antes de guardar, sin convertir ese fallo en éxito.
